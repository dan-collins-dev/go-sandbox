# Go Sandbox

This is a monorepo for a list of learning and practice projects that I used Claude to generate.

### Clone and Run

Install Go 1.27.3 or later, then clone the repository:

```sh
git clone <repository-url>
cd go-sandbox
```

Run a project from the repository root with `go run`:

```sh
go run ./unit-converter-cli
go run ./word-frequency-counter
```

Run only the command for the project you want to try. The Go workspace in the repository root makes both modules available.
